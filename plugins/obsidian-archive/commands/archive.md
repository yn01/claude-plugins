# /obsidian-archive:archive

この会話を要約し、Obsidian の vault にノートを 1 つ保存します。要約は**あなた（メインのエージェント）が書きます**。会話を読めないサブエージェントには任せないでください。

## 1. 本文を書く

この会話全体を振り返り、次の 4 つの見出しで本文を書きます。見出しの文字は変えないでください。後でコードがこの名前で節を探します。

```markdown
## 作業概要
1〜3 段落。最初に何を頼まれ、何を達成し、何が終わらなかったか。

## 主な変更点
- ファイル名を含めた具体的な変更。作成・編集・削除・設定の変更。

## 決定事項・学び
- 採った設計と、その理由。ユーザーからの重要なフィードバック。見つけた問題と解決。

## 未完了・次回への持ち越し
- [ ] 次のセッションで手を付ける具体的な作業（1 行で、主語と対象がわかる形で）
```

- 書くことがない節には `（なし）` と書きます。節そのものは省きません。
- 日付、タイトル、frontmatter、git の変更は書きません。スクリプトが付けます。

## 2. 保存する

本文を標準入力で渡します。区切り文字の行は変えないでください。

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/write-note.mjs" --session "${CLAUDE_SESSION_ID}" --data "${CLAUDE_PLUGIN_DATA}" <<'OBSIDIAN_ARCHIVE_NOTE_END'
## 作業概要
...
OBSIDIAN_ARCHIVE_NOTE_END
```

スクリプトは保存先の絶対パスを 1 行だけ出力します。見出しが欠けていると、何も書かずに終了コード 1 で欠けた見出しを表示します。そのときは本文を直して、もう一度実行してください。

## 3. 報告する

```
✓ セッションノートを保存しました:
  <出力されたパス>
```
